# NuvioScan (v2.0)

NuvioScan is a fast, privacy-first offline document scanner, multi-script Optical Character Recognition (OCR), and searchable PDF generator for Android.

## 📲 1-Click Direct APK Download (For Non-IT Users)
Click the link below on any Android phone to download and install the APK directly (no GitHub login required):
- **[Download NuvioScan.apk](https://github.com/asanaim/LumaScan/releases/latest/download/NuvioScan.apk)**

## ✨ Key Highlights
- **Default Built-In Languages:** **English** and **Bangla + English** work 100% offline out of the box.
- **On-Demand Language Manager (`+ Languages`):** Download **Devanagari (Hindi)**, **Chinese**, **Japanese**, or **Korean** inside the app when needed, and remove them anytime (or long-press their chip) to save storage.
- **Clean Searchable PDFs:** Embeds word-accurate selectable text and the app link strictly in the invisible PDF stream (nothing is visibly printed over your scanned document).
- **Unicode Bangla Smart File Naming:** Preserves Bangla vowel signs (`া`, `ি`, `ৃ`, `ং`, `্`) when auto-naming scanned PDFs.
