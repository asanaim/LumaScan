# VellumScan

VellumScan is a fast, lightweight, privacy-first offline document scanner, multi-script Optical Character Recognition (OCR), and searchable PDF generator for Android.

- **[Download Landing Page](https://asanaim.github.io/LumaScan/)**

## Key Features
- **Hybrid Cupertino Language Manager:** English/Latin and Bangla + English (`ben+eng`) are built-in by default; Devanagari, Chinese, Japanese, and Korean can be downloaded on demand or removed to save space.
- **Clean Searchable PDFs:** Generates compact (~2 MB) searchable PDFs with an invisible selectable OCR text layer and no printed watermarks.
- **ID Card 2-in-1 Page Stitcher:** Combines front and back scans onto a single A4 sheet.
- **Auto-Redact PII:** Permanently blacks out phone numbers, emails, and card/ID numbers from both the image and text layers.
- **Table-to-CSV & Business Card Extractor:** Exports structured tables to `.csv` and saves detected phone/email contacts with one tap.
- **Persistent Offline Library:** Saves scan history locally with instant full-text search.
